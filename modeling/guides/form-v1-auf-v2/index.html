# Formulare V1 -> V2

WARNING

Die Migration von V1 auf V2 muss manuell durchgeführt werden. In dieser Anleitung werden die wichtigsten Besonderheiten aufgeführt und eine Schritt-für-Schritt-Anleitung bereitgestellt

# Schritt für Schritt

# 1. Projekt in der Co-Creation anlegen

Prozesse, die mit dem alten Formularsystem umgesetzt sind, müssen zunächst in der Co-Creation angelegt werden, wenn dies noch nicht geschehen ist.

Hierzu kann die Anleitung Prozess in der Co-Creation anlegen verwendet werden.

Im Anschluss sollte der Prozess in das Projekt hochgeladen werden.

# 2. Formular in VS Code öffnen

Formulare wurden über das Form Tab im BPMN Modeler konfiguriert. Darin ist der Key des Formulars enthalten, der in der Datenbank gespeichert ist. Sollte das Formular lediglich in der Datenbank der Engine vorhanden sein, muss dieses zunächst
