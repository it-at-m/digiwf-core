# Architecture Decision Records (ADRs)

Architecture decision records stellen eine Methode zur Dokumentation von funktionalen oder nicht-funktionalen Architekturentscheidungen dar. Wir verwenden die ADR Vorlage von Michael Nygard (opens new window)

Folgende ADRs sind vorhanden:

  • ADR001 Configure Service
  • ADR002 Use Webclient
  • ADR003 Use hexagonal Architecture style for self-contained systems
  • ADR004 Use hexagonal Architecture by Java package naming
