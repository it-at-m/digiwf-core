# Architecture Decision Records (ADRs)

Architecture Decision Records (ADRs) sind eine Methode zur Dokumentation funktionaler oder nicht-funktionaler Architekturentscheidungen. Wir verwenden die ADR Vorlage von Michael Nygard (opens new window)

Folgende ADRs sind vorhanden:

  • ADR001 Configure Service
  • ADR002 Use Webclient
  • ADR003 Use hexagonal Architecture style for self-contained systems
  • ADR004 Use hexagonal Architecture by Java package naming
  • ADR005 JUnit 5 für Java Unit Tests
