# Beschreibung

Mit den Prozessen

  • Cosys GenerateDocument Test bzw.
  • Cosys GenerateDocument Test (Streaming)

kann das Generieren einer Grußkarte auf Basis eines Cosys-Formulars getestet werden (Der zweite Prozess basiert auf der asynchronen Streaming-Integration, benötigt also den digiwf-connector in der Umgebung).

Die Umgebungsparameter sowie der Grußkartentext können dabei in der Startform eingegeben werden.

Zum Abschluss erhält man im Usertask eine herunterladbare Pdf-Datei mit den gemachten Eingaben.

Da dieses Dokument aus dem S3 Document Storage geladen wird, kann mit diesem Prozess auch gleichzeitig das S3-Feature verifiziert werden.
